# 음성 번역기 사용법

마이크에 대고 말하면 문장 단위로 알아듣고, 바로 번역해서 화면에 보여 주고 소리로 읽어 주는 웹 앱입니다.
처음 열면 **한국어 ↔ Tagalog(필리핀어)** 로 맞춰져 있고, 설정에서 다른 언어로 바꿀 수 있습니다.

이 문서는 개발 지식이 없어도 따라 할 수 있게 썼습니다. 옵션 전체 목록 같은 기술 정보는 [README.md](../README.md)에 있습니다.

## 2. 켜기 (Mac에서)

### 2-1. 터미널 열기

1. 키보드에서 **⌘(command) + 스페이스** 를 누릅니다.
2. `터미널` 이라고 치고 Enter 를 누릅니다. 검은(또는 흰) 글자 창이 뜹니다.

### 2-2. 폴더로 이동

아래 한 줄을 복사해서 터미널에 붙여 넣고 Enter 를 누릅니다.

```
cd ~/voice-translator
```

### 2-3. 서버 켜기

**어디에서 쓸지**에 따라 아래 셋 중 하나를 붙여 넣고 Enter 를 누릅니다. (자세한 차이는 [3장](#3-꼭-같은-와이파이여야-하나요--연결-방식-3가지))

| 쓰는 곳 | 명령 |
|---|---|
| 이 Mac에서만 | `python3 server.py` |
| 같은 Wi-Fi 의 핸드폰 | `python3 server.py --lan` |
| 어디서나 (다른 Wi-Fi, LTE/5G) | `python3 server.py --lan --public` |

### 2-4. 출력 읽기

몇 초 뒤 이런 글이 나옵니다. (`--lan` 으로 켠 예)

```
voice translator (HTTPS, self-signed)
  phone / other devices:  https://172.30.1.97:8787/      ← 핸드폰에서 여는 주소
  this machine:           https://127.0.0.1:8787/        ← 이 Mac에서 여는 주소
  The browser will warn about the certificate once; choose to proceed anyway.
backend: agy/gemini-3.7-flash-low  ready: True  (antigravity login, model gemini-3.7-flash-low)
interpreter session ready                                 ← 이 줄이 나오면 첫 문장부터 빠르게 번역됩니다
```

`--public` 으로 켰다면 한 줄이 더 나옵니다. **이 줄 전체가 공유할 주소**입니다.

```
  anywhere (share this): https://xxxx-xxxx-xxxx.trycloudflare.com/?key=AbCdEf...
```

- `ready: True` 가 보이면 정상입니다. `ready: False` 면 [9장](#9-문제가-생기면)을 보세요.
- 숫자 주소(`172.30.1.97` 부분)는 Wi-Fi 에 따라 달라집니다. **터미널에 실제로 나온 주소**를 쓰세요.

### 2-5. 켜 둔 채로 두기

- **터미널 창을 닫지 마세요.** 닫으면 서버가 꺼집니다. 다른 창 뒤로 보내 두는 건 괜찮습니다.
- **Mac 이 잠들지 않게 하세요.** 잠들면 서버와 외부 주소가 끊깁니다. 가장 확실한 방법은 명령 앞에 `caffeinate -i` 를 붙이는 것입니다. 서버가 도는 동안 Mac 이 잠들지 않습니다.

  ```
  caffeinate -i python3 server.py --lan
  ```

  (`--lan --public` 도 같은 식으로 앞에 붙이면 됩니다. 뚜껑을 덮으면 잠들 수 있으니 열어 두세요.)

## 3. 꼭 같은 와이파이여야 하나요? — 연결 방식 3가지

**아니요. 같은 와이파이가 아니어도 됩니다.** 다만 켜는 명령이 다릅니다.

| 방식 | 명령 | 주소 | 장점 | 주의할 점 |
|---|---|---|---|---|
| **① Mac 에서만** | `python3 server.py` | `http://127.0.0.1:8787/` | 가장 간단, 인증서 경고 없음 | Mac 브라우저에서만 열림 |
| **② 같은 Wi-Fi** | `python3 server.py --lan` | 터미널의 `phone / other devices:` 줄 | 집·사무실 안에서 빠르고 안정적 | 핸드폰이 **같은 Wi-Fi** 여야 함. 처음 열 때 인증서 경고 1회 |
| **③ 어디서나** | `python3 server.py --lan --public` | 터미널의 `anywhere (share this):` 줄 | 다른 Wi-Fi, LTE/5G, 다른 도시에서도 열림. 인증서 경고 없음 | 아래 참고 |

### ③ "어디서나" 방식에서 꼭 알아 둘 것

- **주소가 켤 때마다 바뀝니다.** 서버를 껐다 켜면 새 주소가 나오니, 그때마다 다시 보내 줘야 합니다.
- **접속 키가 필수입니다.** 주소 끝의 `?key=...` 까지 통째로 열어야 합니다. 키를 빼고 열면 화면에 "접속 키 필요" 라고 뜹니다. 한 번 키를 포함해서 열면 그 브라우저는 키를 기억하고, 주소창에서는 키가 사라집니다.
- **이 방식으로 켜면 같은 Wi-Fi 주소(`https://172.30...`)도 키가 필요해집니다.** 헷갈리지 않게, ③ 으로 켰을 땐 그냥 `trycloudflare.com` 주소만 쓰세요.
- 주소를 아는 사람은 누구나 (키가 있으면) 쓸 수 있으니, 필요한 사람에게만 보내세요.
- **Mac 이 켜져 있고 서버가 실행 중이어야** 합니다. 핸드폰만으로는 동작하지 않습니다.
- 인터넷이 느린 곳에서는 번역과 읽어주기가 조금 더 걸릴 수 있습니다.

### 어떤 걸 고를까요?

- 상대와 **같은 공간**에 있고 같은 Wi-Fi 를 쓴다 → **②**
- 상대가 **멀리** 있거나, 내 핸드폰이 Wi-Fi 없이 데이터로만 연결된다 → **③**
- 잘 모르겠다 → **③**. 어디서든 열리고 인증서 경고도 없습니다. 주소만 매번 새로 보내면 됩니다.

## 4. 핸드폰에서 열기

### 4-1. 주소 넣기

- **② 같은 Wi-Fi**: 핸드폰 브라우저 주소창에 터미널의 `phone / other devices:` 주소를 그대로 입력합니다. (예: `https://172.30.1.97:8787/`)
- **③ 어디서나**: 터미널의 `anywhere (share this):` 줄을 복사해서, 카카오톡 "나와의 채팅" 이나 메시지로 핸드폰에 보낸 뒤 링크를 누릅니다. 상대에게도 같은 링크를 보내면 됩니다.

### 4-2. 인증서 경고 넘어가기 (② 방식만)

② 방식은 자체 서명 인증서를 써서 **처음 한 번** "안전하지 않음" 경고가 뜹니다. 정상이니 아래처럼 넘어가면 됩니다.

- **iPhone Safari**: "세부사항 보기" → "이 웹사이트 방문" → 다시 "웹사이트 방문"
- **Android / Mac Chrome**: "고급" → "…(으)로 이동(안전하지 않음)"

③ `trycloudflare.com` 주소는 정식 인증서라 경고가 없습니다.

### 4-3. 마이크 허용

페이지가 열리면 (또는 처음 말하기 버튼을 누르면) **마이크 사용 허용** 을 묻습니다. **허용** 을 누르세요. 거절하면 음성 인식이 안 됩니다. ([9장](#9-문제가-생기면) 참고)

### 4-4. 준비 확인

화면 오른쪽 위 작은 알약 모양 표시가 **연결 중 → 준비됨** 으로 바뀌면 쓸 수 있습니다.

### 추천 브라우저

| 기기 | 브라우저 |
|---|---|
| iPhone / iPad | **Safari** |
| Android | **Chrome** |
| Mac | Chrome 또는 Safari |

음성 인식을 지원하지 않는 브라우저에서는 "이 브라우저는 음성 인식을 지원하지 않습니다" 라고 뜨고, 타이핑 입력만 됩니다.

| **왼쪽 버튼** | **내 언어** 버튼. 처음엔 🇰🇷 한국어. 누르면 한국어로 듣고 상대 언어로 번역합니다. |

| **입력창** | 타이핑으로 번역할 때 씁니다. "한국어 → Tagalog 입력" 처럼 지금 방향이 적혀 있습니다. |

듣고 있는 버튼은 **빨간색으로 바뀌어 천천히 깜빡이고**, 안내문이 **"듣는 중 · 다시 누르면 멈춤"** 으로 바뀝니다.

## 6. 대화하는 방법

핸드폰(또는 Mac)을 두 사람 사이에 두고, **말하는 사람이 자기 언어 버튼을 누르고 말합니다.** 방향을 바꾸는 별도 조작은 없습니다.

### 내가 말할 때 (한국어 → Tagalog)

1. **왼쪽 🇰🇷 한국어** 버튼을 누릅니다. 버튼이 빨간색이 되고 안내문이 "듣는 중" 으로 바뀝니다.
2. 한국어로 **한 문장** 말합니다. 말하는 동안 카드 목록 아래에 인식 중인 내용이 보입니다.
3. 문장을 마치고 잠깐 쉬면, 카드가 생기고 번역이 1~2초 안에 채워지며 **바로 Tagalog 로 읽어 줍니다.**
4. 이어서 다음 문장을 말하면 됩니다. 버튼을 다시 누를 필요 없습니다.

### 상대가 말할 때 (Tagalog → 한국어)

1. 상대가 **오른쪽 🇵🇭 Tagalog** 버튼(안내문 "Pindutin at magsalita")을 누릅니다. 내가 대신 눌러 줘도 됩니다.
2. 상대가 Tagalog 로 말하면, 카드가 생기고 **한국어로 번역해 한국어 음성으로 읽어 줍니다.**

### 멈추기 / 바꾸기

- **멈추기**: 듣고 있는 버튼을 **한 번 더** 누릅니다.
- **차례 바꾸기**: 그냥 **다른 쪽 버튼**을 누릅니다. 바로 그쪽 언어로 듣기 시작합니다.

### 타이핑으로 번역하기

시끄러운 곳이거나 음성 인식이 잘 안 될 때 씁니다.

1. 아래 입력창에 글을 씁니다. 입력창에 적힌 방향(예: "한국어 → Tagalog 입력")대로 번역됩니다.
2. Enter(핸드폰은 "보내기") 또는 **↑** 를 누릅니다.
3. 방향을 바꾸려면 원하는 언어 버튼을 한 번 눌렀다가(듣기 시작) 다시 눌러 끄면, 입력창 방향이 그 언어로 바뀝니다.

### 다시 듣기

카드를 **한 번 누르면** 그 번역을 다시 읽어 줍니다. 상대가 못 들었을 때 유용합니다.

### 잘 되게 하는 요령

- **한 문장씩**, 또렷하게, 문장 끝에서 **잠깐 쉬어** 주세요. 쉬는 순간을 문장의 끝으로 인식합니다.
- 읽어 주는 동안에는 마이크가 잠시 멈춥니다(스피커 소리를 다시 받아 적지 않기 위해서). **읽어주기가 끝난 뒤** 다음 문장을 말하세요.
- 여러 문장을 빠르게 이어 말하면 순서대로 줄을 서서 하나씩 번역됩니다.
- 처음 켠 직후 첫 문장은 몇 초 더 걸릴 수 있습니다(번역 세션과 음성 프로그램 준비). 두 번째부터는 빠릅니다.
- 읽어주기가 잘 들리게 핸드폰 볼륨을 올려 두세요.

## 7. 설정 (⚙︎)

오른쪽 위 **⚙︎** 를 누르면 아래에서 설정 시트가 올라옵니다. 다 바꿨으면 **완료** 를 누르거나 시트를 아래로 끌어내리면 닫힙니다.

| 항목 | 설명 |
|---|---|
| **내 언어** (왼쪽 버튼) | 왼쪽 버튼이 들을 언어 |
| **상대 언어** (오른쪽 버튼) | 오른쪽 버튼이 들을 언어 |
| **번역 자동 읽어주기** | 켜져 있으면 번역이 나오자마자 읽어 줍니다. 끄면 카드를 눌러야 읽어 줍니다. |

고를 수 있는 언어는 12개입니다.

🇰🇷 한국어 · 🇵🇭 Tagalog · 🇺🇸 English · 🇯🇵 日本語 · 🇨🇳 中文 · 🇻🇳 Tiếng Việt · 🇮🇩 Bahasa Indonesia · 🇹🇭 ไทย · 🇳🇵 नेपाली · 🇧🇩 বাংলা · 🇵🇰 اردو · 🇰🇭 ខ្មែរ

- 두 버튼을 같은 언어로 두면 "두 버튼의 언어가 같습니다" 라고 뜨고 번역이 안 됩니다. 하나를 바꾸세요.
- **페이지를 새로 열면 항상 한국어 / Tagalog, 자동 읽어주기 켜짐**으로 돌아갑니다. 다른 언어를 쓸 때는 열 때마다 바꿔 주세요.

## 8. 끄기 / 다시 켜기

### 끄기

서버를 켠 터미널 창을 클릭하고 **Ctrl + C** 를 누릅니다. 창을 닫아도 꺼집니다.

### 다시 켜기

[2장](#2-켜기-mac에서)과 같습니다. 터미널에서

```
cd ~/voice-translator
caffeinate -i python3 server.py --lan            # 또는 --lan --public
```

- ② 같은 Wi-Fi 주소는 보통 그대로지만, Wi-Fi 를 바꾸면 달라집니다. 터미널 출력을 다시 확인하세요.
- ③ 어디서나 주소는 **켤 때마다 새로** 나옵니다. 새 주소를 다시 보내 주세요.

## 9. 문제가 생기면

화면에 나오는 문구별로 정리했습니다.

| 화면 문구 / 증상 | 원인 | 해결 |
|---|---|---|
| **서버 연결 안 됨** | 서버가 꺼졌거나, 핸드폰이 다른 Wi-Fi 에 있거나, Mac 이 잠들었음 | 터미널에서 서버가 돌고 있는지 확인. ② 방식이면 핸드폰과 Mac 이 같은 Wi-Fi 인지 확인. 다른 네트워크에서 쓰려면 ③ 으로 다시 켜기 |
| **접속 키 필요** / "접속 키가 없거나 틀립니다" | ③ 방식인데 `?key=` 없이 열었거나, 서버를 다시 켜서 키가 바뀜 | 터미널의 `anywhere (share this):` 줄을 **`?key=` 까지 통째로** 다시 열기 |
| **준비 중** / "번역 엔진이 아직 준비되지 않았습니다" | Antigravity 로그인이 풀림 | 터미널에서 `agy` 를 한 번 실행해 Google 로그인을 다시 한 뒤, 서버를 껐다 켜기 |
| **음성 인식 오류: not-allowed** (마이크 권한을 허용하세요) | 마이크 권한을 거절함 | iPhone: 설정 → Safari → 마이크 → 허용. Android Chrome: 주소창 왼쪽 자물쇠 → 권한 → 마이크 허용. 그 뒤 페이지 새로 고침 |
| **이 브라우저는 음성 인식을 지원하지 않습니다** | 음성 인식이 없는 브라우저 | iPhone 은 Safari, Android 는 Chrome 으로 열기. 타이핑 입력은 그대로 되지만, 말하기 버튼이 비활성화되어 방향은 한국어 → Tagalog 로 고정됩니다 |
| **소리 재생이 차단되었습니다** | 브라우저가 사용자 조작 없이 소리를 못 내게 막음 | 언어 버튼을 한 번 누르면 그 뒤로는 자동 재생됩니다 |
| **두 버튼의 언어가 같습니다** | 설정에서 두 언어를 같게 둠 | ⚙︎ 에서 하나를 바꾸기 |
| 카드에 **오류:** 가 뜸 | 번역 서버 쪽 일시 오류 | 같은 문장을 다시 말하거나 타이핑. 계속되면 서버를 껐다 켜기 |
| 인식은 되는데 **엉뚱한 글자**로 적힘 | 다른 언어 버튼을 누른 채 말함 | 자기 언어 버튼이 "듣는 중" 인지 확인 |
| **읽어주기 소리가 안 남** | 무음 모드, 볼륨 0, 또는 첫 실행 준비 중 | 볼륨 확인. 첫 문장은 음성 프로그램 준비로 몇 초 걸릴 수 있음. 서버 음성이 실패하면 브라우저 내장 음성으로 대신 읽어 줍니다 |
| 터미널에 **`ready: False`** | Antigravity 로그인 안 됨 또는 `agy` 없음 | 터미널에서 `agy` 실행 후 로그인, 다시 켜기 |
| 터미널에 **`could not open tunnel`** | ③ 방식인데 인터넷이 안 되거나 cloudflared 문제 | 인터넷 확인 후 다시 켜기. 급하면 ② 방식으로 켜기 |
| 터미널에 **`Address already in use`** | 서버가 이미 켜져 있음 | 켜져 있는 것을 그대로 쓰거나, 그 터미널에서 Ctrl + C 로 끈 뒤 다시 켜기 |

## 10. 자주 묻는 질문

**꼭 같은 와이파이여야 하나요?**
아니요. `--lan --public` 으로 켜면 어디서든 됩니다. [3장](#3-꼭-같은-와이파이여야-하나요--연결-방식-3가지)을 보세요.

**핸드폰만으로 쓸 수 있나요?**
아니요. 번역과 음성을 Mac 이 만들기 때문에 Mac 이 켜져 있고 서버가 돌고 있어야 합니다.

**상대에게 링크를 보내면 상대 핸드폰에서도 열리나요?**
네. ③ 방식 주소(`?key=` 포함)를 보내면 상대 핸드폰에서도 같은 화면이 열립니다. 각자 자기 핸드폰으로 써도 되고, 한 대를 같이 봐도 됩니다.

**여러 사람이 동시에 쓰면요?**
됩니다. 다만 번역은 한 번에 한 문장씩 순서대로 처리되어, 겹치면 조금씩 기다립니다.

**대화 기록이 저장되나요?**
아니요. 카드는 그 페이지에만 남고, 새로 고침하면 사라집니다. 서버에도 저장하지 않습니다.

**언어를 바꿨는데 다시 열면 한국어/Tagalog 로 돌아와요.**
의도된 동작입니다. 열 때마다 항상 한국어 / Tagalog, 자동 읽어주기 켜짐으로 시작합니다.

**번역이 이상해요.**
한 문장씩 짧게 말하면 정확도가 올라갑니다. 문장을 타이핑해서 넣어 보면 음성 인식 문제인지 번역 문제인지 구분할 수 있습니다.

**어떤 번역기를 쓰나요?**
Antigravity CLI 의 Gemini 모델(`gemini-3.7-flash-low`)을 Google 구독 로그인으로 씁니다. 읽어주기 음성은 Microsoft Edge 신경망 음성(Tagalog 는 `fil-PH-BlessicaNeural`)입니다.
